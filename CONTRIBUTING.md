# Contributing and promotion

Feature development is coordinated in the working repository. This public repository receives identified, reviewed candidates through `codex/*` publication branches and pull requests to main; it is not synchronized automatically.

Every promotion records its source SHA, included changes/dependencies, real contributors, file inventory, verification evidence and known limitations. Preserve license and contributor credit for existing CargoMesh. Do not relabel another person's work by copying or squashing it.

Use the existing Node/pnpm lockfile and directory layout. Document new required configuration without credentials. Reuse existing contracts, organization isolation and commercial boundaries; do not promise a capability merely because a README directory exists.

The owner currently reserves visual review and has instructed agents not to run additional product tests. Tests/build/live calls remain explicitly unverified until authorized and evidenced. A public draft PR is review material; only an approved release, matching code and verified deployment may be described as the final demo.
